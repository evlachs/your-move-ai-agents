# Sentiment Agent

ИИ-агент, который раз в день читает отзывы из Google Sheets, определяет тональность каждого через YandexGPT и присылает на email сводный отчёт с резюме, распределением и списком негативных отзывов.

## Как это работает

Агент — это цикл (`agent/core.py`), который запускается каждое утро в заданное время:

1. **observe** — `SheetsFetcherTool` скачивает CSV-экспорт таблицы Google Sheets. Каждому отзыву присваивается ID: значение из колонки `ID_COLUMN` или MD5-хэш текста.
2. **plan** — из полученных отзывов выбрасываем уже проанализированные (по ID из SQLite). Если новых нет — агент завершает работу. Берём не более `MAX_REVIEWS_PER_RUN` отзывов за один запуск.
3. **act (анализ)** — каждый новый отзыв передаётся в `YandexGPTTool.analyze_review()`: GPT определяет тональность (`позитивный` / `нейтральный` / `негативный`) и выделяет до 3 ключевых тем.
4. **act (резюме)** — `YandexGPTTool.generate_summary()` генерирует итоговый абзац по всей выборке: общее настроение, главные проблемы, рекомендации.
5. **act (отправка)** — `EmailNotifier` рендерит `templates/digest.html` и отправляет отчёт через SMTP.
6. **observe** — ID всех успешно обработанных отзывов сохраняются в SQLite. Если отправка не удалась — память не обновляется, при следующем запуске попробуем снова.

## Источник данных: Google Sheets

Таблица может быть создана вручную или заполняться через Google Forms. Для доступа агента без OAuth:

**Вариант А (рекомендуется):** Файл → Поделиться → Опубликовать в интернете → выбрать лист → CSV. Полученный URL указать в `SHEETS_CSV_URL`.

**Вариант Б:** Файл → Поделиться → Все с ссылкой → Читатель. Тогда URL экспорта:  
`https://docs.google.com/spreadsheets/d/{ID}/export?format=csv`

## Память

`agent/memory.py` хранит в SQLite ID уже проанализированных отзывов. Это исключает дубли между ежедневными отчётами. При новом запуске агент обрабатывает только отзывы, добавленные после предыдущего запуска.

## Переменные окружения

См. `env.example`. Ключевые:

- `SHEETS_CSV_URL` — URL CSV-экспорта публичной таблицы Google Sheets (обязательно).
- `TEXT_COLUMN` — название колонки с текстом отзыва (по умолчанию `Отзыв`).
- `ID_COLUMN` — колонка с уникальным ID строки; пусто = хэш текста (необязательно).
- `MAX_REVIEWS_PER_RUN` — сколько новых отзывов обрабатывать за один запуск (по умолчанию `50`).
- `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` — доступ к YandexGPT.
- `SMTP_*`, `EMAIL_FROM`, `EMAIL_TO` — доставка отчёта.
- `DIGEST_HOUR`, `DIGEST_MINUTE`, `TIMEZONE` — время ежедневного запуска (по умолчанию `09:00 Europe/Moscow`).

## Запуск

Локально:

```bash
cp env.example .env   # заполнить своими значениями
pip install -r requirements.txt
mkdir -p data

python main.py --once   # один проход цикла агента (для проверки)
python main.py          # планировщик — отчёт каждый день в заданное время
```

В Docker:

```bash
docker build -t sentiment-agent .
docker run --env-file .env -v $(pwd)/data:/data sentiment-agent
```

## Стек

- Python 3.11
- YandexGPT (REST API) — анализ тональности и генерация резюме
- `requests` — загрузка CSV из Google Sheets
- Jinja2 + `smtplib` — рендер и отправка HTML-отчёта
- APScheduler — расписание (раз в день)
- SQLite — память между запусками
