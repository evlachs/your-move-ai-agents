# Email Digest Agent

ИИ-агент, который дважды в день проверяет рабочую почту по IMAP и присылает дайджест новых писем — с кратким резюме и оценкой важности от YandexGPT.

## Как это работает

Агент — это цикл (`agent/core.py`), который запускается дважды в день — в обед и в конце рабочего дня:

1. **observe** — `MailFetcherTool` подключается по IMAP и получает письма с UID больше последнего обработанного (или за сегодня — при первом запуске).
2. **plan** — если новых писем нет, агент всё равно сдвигает границу UID в памяти (чтобы не упереться в старую точку отсчёта) и завершает работу.
3. **act (анализ)** — каждое письмо прогоняется через `YandexGPTTool.analyze_email()` — получаем краткое резюме и пометку важности (высокая/средняя/низкая).
4. **act (тема)** — генерируется тема письма-дайджеста.
5. **act (отправка)** — `EmailNotifier` рендерит `templates/digest.html` (важные письма — отдельным блоком) и отправляет через SMTP.
6. **observe** — память обновляется (новый UID) только после успешной отправки. Если отправка не удалась — следующий запуск повторит попытку с тех же писем.

## Память

`agent/memory.py` хранит в SQLite UID последнего письма, попавшего в дайджест, по почтовому ящику — это не даёт письмам попадать в дайджест дважды и переживает перезапуски агента.

## Переменные окружения

См. `env.example`. Ключевые:

- `IMAP_HOST`, `IMAP_PORT`, `IMAP_USER`, `IMAP_PASSWORD`, `IMAP_MAILBOX` — доступ к рабочей почте (для Яндекс Почты — пароль приложения, не основной пароль).
- `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` — доступ к YandexGPT.
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `EMAIL_FROM`, `EMAIL_TO` — доставка дайджеста (получатель может совпадать с проверяемым ящиком или быть другим адресом).
- `LUNCH_HOUR`/`LUNCH_MINUTE`, `EVENING_HOUR`/`EVENING_MINUTE`, `TIMEZONE` — расписание двух запусков в день.

## Запуск

Локально:

```bash
cp env.example .env   # заполнить своими значениями
pip install -r requirements.txt

python main.py --once   # один проход цикла агента (для проверки/ручного запуска)
python main.py          # планировщик — два запуска в день по расписанию
```

В Docker:

```bash
docker build -t email-digest-agent .
docker run --env-file .env -v $(pwd)/data:/data email-digest-agent
```

## Стек

- Python 3.11
- `imaplib`/`email` (стандартная библиотека) — чтение почты по IMAP
- YandexGPT (REST API) — резюме и важность писем
- Jinja2 + `smtplib` — рендер и отправка HTML-дайджеста
- APScheduler — расписание (два запуска в день)
- SQLite — память между запусками
