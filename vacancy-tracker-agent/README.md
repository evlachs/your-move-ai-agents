# Vacancy Tracker Agent

ИИ-агент, который регулярно проверяет HH.ru по заданным фильтрам и присылает дайджест новых вакансий — с оценкой интереса и ключевыми требованиями от YandexGPT.

## Как это работает

Агент — это цикл (`agent/core.py`), который запускается каждые N часов:

1. **observe** — `HHApiTool` запрашивает свежие вакансии через публичный API HH.ru (авторизация не нужна). Параметры поиска берутся из конфига: ключевые слова, регион, зарплата, опыт, тип занятости.
2. **plan** — из полученных вакансий выбрасываем уже виденные (сравниваем ID с памятью в SQLite). Если новых нет — агент завершает работу до следующего запуска.
3. **act (анализ)** — каждая новая вакансия передаётся в `YandexGPTTool.analyze_vacancy()`. GPT оценивает вакансию (`интересная` / `средняя` / `не подходит`) с учётом профиля соискателя из `CANDIDATE_PROFILE` и выделяет до 4 ключевых требований.
4. **act (отправка)** — `EmailNotifier` рендерит `templates/digest.html` (интересные вакансии — первыми) и отправляет через SMTP.
5. **observe** — ID всех новых вакансий сохраняются в SQLite, независимо от оценки GPT. Если отправка не удалась — память не обновляется, при следующем запуске попробуем снова.

## Память

`agent/memory.py` хранит в SQLite ID уже показанных вакансий. Это исключает дубли между запусками и переживает перезапуски агента.

## Переменные окружения

См. `env.example`. Ключевые:

- `HH_SEARCH_TEXT` — ключевые слова для поиска (обязательно), например `"Python разработчик"`.
- `HH_AREA_ID` — ID региона: `1` = Москва, `2` = СПб, `113` = вся Россия. Полный список: `https://api.hh.ru/areas`.
- `HH_SALARY_FROM`, `HH_ONLY_WITH_SALARY` — фильтр по зарплате.
- `HH_EXPERIENCE` — уровень опыта: `noExperience`, `between1And3`, `between3And6`, `moreThan6`.
- `CANDIDATE_PROFILE` — краткое описание соискателя. YandexGPT использует его как контекст для оценки вакансий. Можно оставить пустым.
- `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` — доступ к YandexGPT.
- `SMTP_*`, `EMAIL_FROM`, `EMAIL_TO` — доставка дайджеста.
- `CHECK_INTERVAL_HOURS` — интервал проверки (по умолчанию `4`).

## Запуск

Локально:

```bash
cp env.example .env   # заполнить своими значениями
pip install -r requirements.txt
mkdir -p data

python main.py --once   # один проход цикла агента (для проверки)
python main.py          # планировщик — проверка HH.ru каждые N часов
```

В Docker:

```bash
docker build -t vacancy-tracker-agent .
docker run --env-file .env -v $(pwd)/data:/data vacancy-tracker-agent
```

## Стек

- Python 3.11
- HH.ru API (публичный REST API) — поиск вакансий
- YandexGPT (REST API) — оценка релевантности вакансий
- Jinja2 + `smtplib` — рендер и отправка HTML-дайджеста
- APScheduler — расписание
- SQLite — память между запусками
